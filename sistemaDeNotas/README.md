Guia de Execução do Projeto "Sistema de Notas"

PRÉ-REQUISITOS:
- Java Development Kit (JDK) instalado (versão 8 ou superior).
- Um terminal (PowerShell, CMD ou terminal do VS Code).

ESTRUTURA DOS FICHEIROS:
Para que o programa funcione corretamente com os pacotes, 
certifique-se de que a estrutura de pastas está assim:

[Pasta Raiz do Projeto]
 └── sistemaDeNotas/
      ├── Main.java
      ├── Aluno.java
      └── Diario.java

COMO RODAR O PROJETO (A partir da pasta raiz):

1. Abra o terminal na pasta raiz (onde fica a pasta "sistemaDeNotas").

2. Compile todos os ficheiros de uma vez:
   javac sistemaDeNotas/*.java

3. Execute o programa principal chamando o pacote:
   java sistemaDeNotas.Main
